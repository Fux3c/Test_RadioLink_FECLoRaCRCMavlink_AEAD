# Wiring of NRS rocket
Visual guide for wiring each electrical component of the rocket.
## Usage
Open nrs-wiring.html.
## Building
```shell
make build
```
## Dependencies
### Optional virtualenv
```shell
python3 -m venv .venv
```
### Requirements
```shell
pip3 -r requirements.txt
```
### Drawio
[Install](https://www.drawio.com)
