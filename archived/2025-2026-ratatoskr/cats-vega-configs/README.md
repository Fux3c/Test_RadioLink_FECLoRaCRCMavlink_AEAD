# Ratatoskr CATS-Vega configurations

This repo contains configuration files for the CATS-Vega flight computers that will be used for the launch of Ratatoskr

FC1 and FC2 are the flight computers that are planned to be used, while FC3 is our backup, and will be configured as needed (hopefully not at all).
